# GRAPH AI Course Portfolio

Portfolio site for the GRAPH Courses "Generative AI for Work & Research" cohort. A single self-contained `index.html` (no frameworks), built with Claude Code and served by GitHub Pages.

Design adapted from [Contour](https://github.com/mobiusone-org/hugo-contour) by MobiusOne.org (MIT License, see `LICENSE-contour`).
